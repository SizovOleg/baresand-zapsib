Класса `disputed` (спорный) в v7 нет: 5 спорных контуров v4 (0,31 км²; 6 строк после разреза контура 412698, часть
900012) автор разрезал или классифицировал (step6_rule = v5_mixed_owner).

**Точность (решение автора 13.10.2026).** Приводится только для эоловых песков: точность пользователя 94,9 % (95 % ДИ
86,2-99,5), производителя 86,0 % (73,6-98,9), F1 0,90 (0,82-0,99), площадь по эталону 3 024 км² (2 508,6-3 540,6).
Источник: `exports/qc/owner_click/V1/accuracy_V1+V1b+V1c_split100_U.md` (стратифицированная выборка 276 контуров, эталон:
метка автора в слепом окне, `python/119_validation_v4.py`). Объект оценки: версия карты на момент отбора V1 (до
исправлений v5-v7), домен U (часть маски, не размеченная до V1: 573 438 контуров, 8 061,0 км²). Это не оценка точности
итогового слоя v7. Отчёт `..._U_baresand_genesis_v7_cf.md` не является пересчётом по классам v7: все 276 единиц
сохраняют класс на момент отбора, а класс заменён только у единицы 395404 (контрфактическая подстановка правила v7,
анализ чувствительности, приложение S6): эоловые 95,1 %, 86,0 %, F1 0,903 при той же площади по эталону. Общая
точность 91,6 % (84,7-98,0) по трём классам уходит в приложение.

**Техногенные пески** описываются как экспертный класс по косвенным признакам: на шаге 3 OSM, ЕГРН, история
поверхности (Hansen 2000, Landsat 1984-1995), правки эксперта; позже метки автора и переводы v7. Подложка Sentinel-2
2017-2019 на шаге 3 не использовалась (только на шагах 4-5 и в признаках модели переноса шага 6). Показатели точности
для класса не приводятся, и весь класс контрольной выборкой не проверялся. Партии T1, T2
(`exports/qc/aeolian_techno*/result_*.md`) и T3 (`exports/qc/control_v7/report.md`, 142) проверяли только переводы v7
(1 810 контуров, 19,91 км², около 1 % класса) и остаточный техноген среди эоловых контуров вблизи инфраструктуры
([METHODS.md](METHODS.md), раздел 7.6).

## 4. Поля слоя genesis

133 поля. Роль: **О** основное (входит в публичный слой), **С** служебное (история каскада, флаги, улики; для
воспроизводимости), **П** постоянное или устаревшее (одно значение во всём слое). Пустые значения: в текстовых полях
встречаются и NULL, и пустая строка; NULL в числовых полях значит «не считалось для этого контура».

и промышленные полигоны слоя industrial (промзоны городов). Файлы PBF скачаны 05.09.2026 с адресов `*-latest.osm.pbf`;
точная дата выгрузки внутри файла и хеши не записаны. Атрибуция при любой выкладке и на картах:

> Содержит данные © участники OpenStreetMap, доступные по лицензии Open Database License (ODbL) 1.0,
> https://www.openstreetmap.org/copyright

Классы генезиса получены с использованием OSM: это производная работа (Produced Work), достаточно атрибуции. Поля,
напрямую производные от OSM (раздел 9), делают таблицу производной базой данных (Derivative Database): при их
публикации эта часть должна распространяться по ODbL (share-alike) с указанием способа получения. Поэтому публичный слой
предлагается без этих полей; если автор захочет выложить полную версию, её лицензия ODbL 1.0, а не CC BY.

**ЕГРН (Росреестр, НСПД nspd.gov.ru).** Сведения получены выгрузкой с публичной кадастровой карты (WMS НСПД; в
GetCapabilities указано Fees none, AccessConstraints none: `python/69_step3_nspd_download.py`); участки для слоёв 133
взяты из проекта автора `E:\cadastre-local` (ЯНАО, ХМАО на 08.09.2026, Красноярский край на 06.10.2026), из них же 151
берёт земли населённых пунктов и садоводческие участки для территории населённых пунктов. Условия
повторного распространения выгрузок реестра этим не устанавливаются, поэтому выгрузки (parcels, кадастровые номера,
ВРИ) в выкладку не включаются; публикуются только производные классы (в отводе, превышение отвода, без отвода) с
формулировкой:

> Сопоставление с участками ЕГРН (по сведениям НСПД на 08.09.2026 и 06.10.2026) пространственное: «отвод под объект»
> определён по категории и ВРИ участка, а не по документам; превышение отвода и отсутствие отвода указывают на места
> для адресной проверки и не устанавливают нарушений.

Слои «превышение отвода» и «без отвода» в сочетании с кадастровыми номерами позволяют назвать конкретных
правообладателей как возможных нарушителей; публиковать их без номеров и с этой оговоркой (вопрос 5). Поскольку
участки ЕГРН не публикуются, внешний читатель не сможет повторить сопоставление (133, 151) по выкладке: для него
результатом служат опубликованные производные слои, а повтор оверлея возможен только при наличии собственной выгрузки
ЕГРН на те же даты.
