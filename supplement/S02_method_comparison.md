# S2. Сравнение методов на эталонной сцене Надымских песков

Сцена Sentinel-2 тайла 42WXT от 11.07.2024. Методы классификации сравнивались по площади маски и визуальной оценке по
снимку высокого разрешения (src/gee_scripts/10_method_threshold.js - 16_diff_rf_vs_combined.js, сводка
14_method_comparison.js). Таблица поясняет выбор двухэтапного классификатора для массовой обработки.

Таблица S2.1. Площадь песков на эталонной сцене по разным методам

| Метод | Площадь, км² | Оценка по снимку |
|---|---|---|
| пороговый (NDVI, BSI, NDRE, яркость, MNDWI) | 11,77 | выделяет только ядра раздувов |
| K-средних (15 кластеров) | 127,65 | перевыделение |
| случайный лес по спектральным признакам | 83,97 | одиночный шум по краям раздувов |
| двухэтапный: предфильтр, случайный лес, постобработка* | 100,05 | принят для массовой обработки |
| случайный лес по эмбеддингам AlphaEarth Foundations** | 82,86 | маска накрывает тундру вокруг раздувов, включая лишайник и торф |

\* Пробная конфигурация: предфильтр NDVI ≤ 0,25, снег маскируется; в массовой обработке NDVI ≤ 0,40, снег не
маскируется (docs/METHODS.md, раздел 2).

\*\* Площадь при агрегации обучающей выборки в Google Earth Engine с параметром tileScale = 4; при tileScale = 1
получено 197,81 км². На этой сцене эмбеддинги слабо разделяют песок и лишайниковую пустошь (косинусное сходство средних
эмбеддингов классов 0,955), тогда как средние значения NDRE двух классов различаются заметно (0,037 и 0,217).
