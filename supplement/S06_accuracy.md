# S6. Оценка точности

## Объект оценки и эталон

Оценивалась правильность атрибуции генезиса внутри маски для версии карты до точечных правок (классы на момент отбора
выборки, S10, табл. S10.1). Совокупность для отбора (проверяемая часть маски, домен U) включает 573 438 контуров площадью
8 061,0 км². Из отбора исключены 1 587 контуров (94,4 км², 1,2 % площади маски), размеченных ранее при разработке правил
(домен E, табл. S6.2). Оценка не характеризует полноту маски и точность отдельных пикселей.

Эталон: класс, присвоенный экспертом в окне проверки по снимку Esri World Imagery и летнему композиту Sentinel-2 без
показа класса карты (S5). Эталонные категории: отмель, эоловый, техногенный, не песок, смешанный контур. Метки выборки
затем внесены в итоговый слой, поэтому во всех расчётах единицам выборки возвращается класс на момент отбора.

## Выборка

Страты: класс карты (отмели, эоловые, техногенные, неопределённые) и площадь контура (менее 1 га, 1-20 га, 20-100 га,
не менее 100 га). Выборка набиралась в три приёма: V1 (176 контуров во всех стратах), V1b (60 контуров не менее 20 га) и
V1c (40 контуров не менее 100 га); объёмы и страты каждого приёма задавались до его разметки. Страта крупных
неопределённых контуров (4 контура) обследована сплошь. Итоговое разбиение и объёмы приведены в табл. S6.1.

## Расчёт

Площадь ячейки матрицы ошибок (класс карты k, эталонный класс j) оценивалась по формуле

Â_kj = Σ_h A_h · (Σ_{i∈s_h} a_i · I(m_i = k, r_i = j) / Σ_{i∈s_h} a_i), (S6.1)

где A_h: площадь страты h в домене U, км²; s_h: единицы выборки страты h; a_i: площадь единицы i, км²; m_i: класс
карты единицы i; r_i: её эталонный класс; I: индикатор (1 при выполнении обоих условий, иначе 0). Суммирование ведётся
по всем стратам схемы. В основном расчёте m_i совпадает с классом страты, и (S6.1) сводится к формуле (2) статьи.
Точность пользователя класса равна отношению диагональной ячейки к строке карты, точность производителя: отношению
диагональной ячейки к столбцу эталона. Общая точность трёх основных классов равна отношению суммы диагональных ячеек к
сумме строк отмелей, эоловых и техногенных песков; в варианте с неопределённой частью в знаменатель добавляется строка
неопределённых. Неопределённые контуры карты считаются неверно атрибутированными при любой эталонной метке, контуры,
признанные эталоном смешанными, учитываются как ошибка. Доверительные интервалы уровня 95 % получены бутстрэпом внутри
страт (2 000 повторов). Расчёт: src/python/118_validation_v4_pop.py (совокупность), 119_validation_v4.py (оценки).

## Чувствительность к правилу точечных правок

Правило перевода эоловых контуров вблизи инфраструктуры в техногенные (S10) применялось к итоговому слою без единиц
выборки. Чтобы оценить его влияние на оценку точности, автоматическая ветвь правила применена к единицам выборки
(контрфактическая подстановка). Геометрическому условию (класс на момент отбора эоловый, не менее 5 га, не далее 20 м
от техногенного контура или построенной дороги OSM) отвечают пять единиц. Их описали два запуска модели по протоколу S9
(п. 6) по снимкам того же вида (табл. S6.4). Оба запуска отнесли к техногенным только единицу 395404; в расчёте её
класс карты заменён на техногенный, состав страт, их площади и эталон не менялись.

## Свойства оценок

Бутстрэп внутри страт воспроизводит только наблюдавшиеся исходы, поэтому в стратах без выявленных ошибок интервалы
занижены. Интервалы не учитывают долю отбора из конечной совокупности и последовательный добор крупных страт и являются
приближёнными.

Редкие категории эталона. Эффективный объём выборки по неравенству весов (по Кишу) составляет 102,8 контура. При этом
допущении верхняя граница двустороннего 95 %-ного интервала Клоппера-Пирсона для доли площади категории «не песок»
(0 из 276) составляет 3,5 % (до 284 км²), для контуров, признанных смешанными (7 из 276, 1,6 % площади), 6,3 %
(до 508 км²). Для стратифицированной оценки отношения по контурам разной площади эти границы ориентировочны.

Тип отмели (второстепенный атрибут) совпал у 88 из 91 отмели карты, подтверждённой эталоном как отмель: 95,8 % площади
с весами страт.
