# S4. Уточнение генезиса по рельефу (шаг 5)

Превышение над локальным базисом рассчитывалось по формуле (1) статьи:

h_local600 = z_med − z_p5,

где z_med: медиана высот ArcticDEM (версия 4.1) внутри контура, м; z_p5: 5-й процентиль высот контура с внешним буфером
600 м, м. Превышение над тальвегом h_chan: разность медианы высот контура и 5-го процентиля отметок руслового коридора
MERIT Hydro. Статистики считались на сетке 10 м внутри контура и 30 м для базиса. Разность высот устраняет смещение
эллипсоидальных отметок ArcticDEM относительно уровня моря.

На эталоне разработки из 640 контуров локальный базис определён для 99,1 % контуров. Площадь под ROC-кривой для пары
«эоловые пески / речные отмели» составила 0,94 (при базисе по берегу постоянной воды JRC GSW 0,90), для пары «эоловые
пески / озёрные отмели» 0,91, на контурах сопоставимой площади (0,5-5 га) 0,94. Медианы h_local600: эоловые пески 6,04 м
(межквартильный размах 3,4-9,4 м), речные отмели 0,49 м, озёрные отмели 0,54 м.

Пороги правил подобраны на целевой выборке из 290 контуров (153 неопределённых и 137 эоловых у русел), не входивших в
эталоны разработки и в отложенную выборку. Минимальная чистота класса на выборке: 80 % для добавления контуров в класс и
85 % для снятия контуров из класса.
