# Интерактивная карта

Интерактивная карта оголённых песков севера Западной Сибири в Google Earth Engine:
<https://nodal-thunder-481307-u1.projects.earthengine.app/view/baresand>

Исходный код: [baresand_app.js](baresand_app.js) (Code Editor, ui API, JavaScript ES5). Слои карты загружены в ассеты
Earth Engine скриптом [../src/python/150_gee_upload.py](../src/python/150_gee_upload.py); статистика правой панели
рассчитана скриптом [../src/python/155_app_stats.py](../src/python/155_app_stats.py) по точным геометриям итоговых слоёв.

## Интерфейс

Левая панель содержит группы слоёв, блок выгрузки контуров и сведения о проекте; правая панель показывает статистику.
У включённого слоя раскрываются легенда и регулятор непрозрачности. Щелчок по карте открывает карточку атрибутов
включённых слоёв. Подложки: светлая, спутник, рельеф.

| Группа | Слой | Содержание |
|---|---|---|
| результат | генезис песков | итоговый слой: эоловые пески, отмели (речные, озёрные, морские), техногенные пески, неопределённые; классы отключаются в легенде; карточка контура: класс, площадь, источник класса |
| | плотность песков | суммарная площадь контуров класса (эоловые, отмели, техногенные) в ячейках, га/км²; ячейка меняется с масштабом: 10 км (до масштаба 6), 5 км (7-8), 2 км (с 9), её можно задать явно |
| | техногенные пески и отводы ЕГРН | группы «в отводах», «превышение отвода», «объекты без отвода» и обобщённая маска земельных отводов; карточка: группа участка, вид объекта, доля в отводе, площадь, возраст поверхности |
| снимки и маска | сцены Sentinel-2 | сцены, по которым классифицированы тайлы ([S7](../supplement/S07_scenes.md)): обзорная мозаика или сцены выбранного тайла; синтезы в ложных цветах (B8, B4, B3), естественных цветах (B4, B3, B2) и SWIR (B12, B11, B4) |
| | маска песка, первичный вектор | растр маски 10 м и контуры первичного вектора |
| справочные слои | граница района, покрытие маски, тайлы MGRS | район работ 1 068 411 км², покрытие 128 тайлов |
| | инфраструктура OSM | дороги (основные, прочие, грунтовые, зимники), железные дороги, трубопроводы, ЛЭП, промышленные площадки и карьеры |
| | рельеф, повторяемость воды, лесной покров | ArcticDEM v4, JRC Global Surface Water, Global Forest Change 2019 v1.7 |

Правая панель «Статистика»: выбор территории (весь район работ, видимая область карты или административный район,
который выбирается также щелчком по карте или по столбцу рейтинга), площадь песков, диаграмма классов, распределение
техногенных песков по группам отводов и по возрасту поверхности, рейтинг районов по выбранному показателю, широтный
профиль по поясам 1°. Для видимой области статистика рассчитывается по растрам плотности 2 км.

## Выгрузка контуров

Блок «Скачать контуры» формирует ссылку на контуры видимой области (масштаб 8 и крупнее, до 50 000 контуров) для слоёв
генезиса, трёх групп техногенных песков и обобщённой маски отводов в форматах GeoJSON, KML и CSV. Геометрия слоёв карты
упрощена на 10 м (размер пикселя маски); поля выгрузки: [../docs/DATA.md](../docs/DATA.md), разделы 4.6 и 5.

## Отображение

- На мелких масштабах заливка генезиса берётся из растра классов с ячейкой 50 м, с масштаба 9 из векторного слоя;
  границы контуров рисуются с масштаба 11, группы техногенных песков и маска отводов с масштаба 8.
- Растр маски песка показывается с масштаба 10.
- Карточка по щелчку запрашивает объекты в радиусе трёх пикселей экрана и выбирает ближайший.

## Собственная копия

Скрипт выполняется в Code Editor. Пути к ассетам задаются в разделе 1 скрипта (`ROOT_ASSETS`, `PROJECT`, `ASSETS`),
ссылки панели в `LINKS`. Ассеты загружаются скриптом 150 (`--layer <слой>`, `--density-grid <м>` для растров
плотности, `--class-raster` для растра классов); при публикации в виде Earth Engine App ассеты должны быть доступны
приложению на чтение.

Логику панели без обращения к Earth Engine проверяет `node gee_app/test/mock_run.js` (заглушки `ee` и `ui`: все
переключатели, списки, смена масштаба, щелчок по карте, карточки атрибутов, графики).

Источники данных и атрибуция: [../docs/DATA.md](../docs/DATA.md), раздел 10.
